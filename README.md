## ✨ 这是什么？

一个**程序员专属的打字测速游戏**：

- 打一段**真实代码**（Python / JavaScript / Java / SQL / Go）
- 实时统计 **WPM（字/分钟）、准确率、用时**
- 正确字符绿色、错误红色、当前字符高亮
- **历史最佳成绩**本地保存，挑战自己
- 完成自动统计，可随时换一段重新挑战

**为什么测速要用代码？** 因为写代码的节奏（缩进、符号、大小写切换）和普通英文完全不同，用代码练打字才贴合程序员真实场景。

## 🎮 怎么玩？

1. **选语言**：Python / JS / Java / SQL / Go 任选
2. **点「开始」**：从第一个字符开始计时
3. **打字**：照着代码逐字符打，正确绿色、错误红色
4. **完成**：自动统计 WPM / 准确率 / 用时，刷新历史最佳

## 📊 指标说明

| 指标 | 说明 |
|---|---|
| WPM | 每分钟打出多少个"单词"（每 5 字符算 1 个） |
| 准确率 | 正确字符 ÷ 总字符 |
| 用时 | 从第一个字符到最后一个字符 |
| 历史最佳 | 本地保存的最高 WPM，下次挑战自己 |

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript（单文件，无构建）
- localStorage 保存历史最佳
- 无任何外部依赖，可离线使用
